OVERVIEW
This project demonstrates and compares Heap Sort algorithms and Merge Sort algorithms

This allows users to:
-Create custom lists
-Generate random datasets
-Load input data from external text files
-Compare execution times between algorithms

This project was created with Python and focuses on algorithm analysis, performance comparison and user interaction. Storing results inside of an SQLite database for later analysis.

FEATURES
-Merge Sort implementation
-Heap Sort implementation
-Random integer and float transaction generation
-Custom user input sorting
-External text file dataset loading
-SQLite database result storage
-Session tracking
-Runtime comparison
-Complexity analysis menu

TECHNOLOGY USED
-Python
-SQLite3
-VS Code
